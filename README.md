# 墙纸群无缝图案本地编辑器

纯前端实现：Svelte + TypeScript + Canvas 2D + gl-matrix，数据保存在浏览器 IndexedDB，不需要服务端。

## 运行

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm run test:groups
npm run test:revisions
npm run test:db
npm run test:workspace
```

`test:groups` 对全部 17 个墙纸群做蒙特卡洛铺排检查，确认每个群的陪集基本域在平移晶格下恰好覆盖平面，内部点不重不漏。`test:revisions` 检查修订载荷校验、分支/父子语义、差异对比与旧版迁移规划；`test:db` 在内存 IndexedDB 上验证 v1→v2 无损迁移、修订不可变与级联删除；`test:workspace` 端到端模拟创建检查点、分支切换、安全恢复、防抖世代与刷新重开。

## 设计要点

- 支持 17 个二维墙纸群：`p1, p2, pm, pg, cm, pmm, pmg, cmm, p4, p4m, p4g, p3, p3m1, p31m, p6, p6m`。
- 平移、旋转、反射和滑移反射都表示为 gl-matrix `mat3`，实例由 `T(n,m) · Cᵢ` 生成；不会通过手工复制几块图形伪造群轨道。
- 基本域逐实例裁切。跨基本域或周期边界的路径仍只有一个源路径，其每个矩阵像分别被裁切。
- 编辑源对象的路径节点、颜色、透明度会同步更新所有实例；对象 `id` 在撤销/重做中保持不变。
- 点选任意实例会记录 `objectId@coset:n,m`，双击或点击“定位到原始对象”可回到唯一源对象。
- 滑移反射、旋转中心、镜面和透明边缘都有可视化标记；内置滑移、四重旋转、p6m 样例。
- “接缝/导出”页生成透明 PNG 周期单元，并用同一个单元重复 3×3 检查接缝；三角晶格导出 2×2 原胞形成矩形超级周期。
- 工程以 IndexedDB 本地保存；编辑会自动防抖保存，也可 Ctrl/⌘+S 立即保存。

## 本地修订与分支检查点

- 数据分三个对象存储：`projects`（工程元数据与分支计数器）、`revisions`（不可变修订，含父修订 ID、分支名与完整载荷）、`workingCopies`（每工程一份的工作副本，含当前分支、基修订与世代号）。
- 修订载荷完整包含群、晶格尺寸、全部路径、样式与对象 ID，画布选择、实例定位与 PNG 导出始终对应当前修订。
- 创建检查点把当前工作副本固化为不可变修订，随后工作副本切到全新分支，继续编辑自然形成新分支上的后代；恢复旧检查点同样以它为父修订开启新分支，旧版本与对象 ID 不被篡改，恢复本身可撤销。
- 自动防抖保存携带工作副本世代票据，并在串行写队列内复核；加载其他工程或切换修订后，旧计时器的迟到内容不会写回新上下文（切换工程前会先冲刷旧上下文）。
- IndexedDB 从 v1 升级时，已有工程在升级事务内无损迁移为「元数据 + main 分支初始修订 + 新分支工作副本」，损坏记录保持原样不阻塞升级。
- “修订/分支”页提供时间线、分支过滤、两个修订的群/对象差异对比与安全恢复入口（未固化修改会先提示是否自动创建检查点）；损坏或格式不支持的修订明确报错并被隔离，不会替换当前画布与既有检查点。
