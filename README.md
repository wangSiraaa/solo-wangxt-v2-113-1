# 墙纸群无缝图案本地编辑器

纯前端实现：Svelte + TypeScript + Canvas 2D + gl-matrix，数据保存在浏览器 IndexedDB，不需要服务端。

## 运行

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm run test:groups
npm run test:revisions
```

`test:groups` 对全部 17 个墙纸群做蒙特卡洛铺排检查，确认每个群的陪集基本域在平移晶格下恰好覆盖平面，内部点不重不漏。`test:revisions` 检查修订图逻辑（纯函数）与 IndexedDB 迁移/检查点/恢复/世代守卫（fake-indexeddb 集成）。

## 设计要点

- 支持 17 个二维墙纸群：`p1, p2, pm, pg, cm, pmm, pmg, cmm, p4, p4m, p4g, p3, p3m1, p31m, p6, p6m`。
- 平移、旋转、反射和滑移反射都表示为 gl-matrix `mat3`，实例由 `T(n,m) · Cᵢ` 生成；不会通过手工复制几块图形伪造群轨道。
- 基本域逐实例裁切。跨基本域或周期边界的路径仍只有一个源路径，其每个矩阵像分别被裁切。
- 编辑源对象的路径节点、颜色、透明度会同步更新所有实例；对象 `id` 在撤销/重做中保持不变。
- 点选任意实例会记录 `objectId@coset:n,m`，双击或点击“定位到原始对象”可回到唯一源对象。
- 滑移反射、旋转中心、镜面和透明边缘都有可视化标记；内置滑移、四重旋转、p6m 样例。
- “接缝/导出”页生成透明 PNG 周期单元，并用同一个单元重复 3×3 检查接缝；三角晶格导出 2×2 原胞形成矩形超级周期。
- 工程以 IndexedDB 本地保存；编辑会自动防抖保存，也可 Ctrl/⌘+S 立即保存。

## 修订与分支检查点

- 数据分三个对象仓库分别保存：工程元数据（`projects`）、不可变修订（`revisions`，含父修订 id 与分支名）、工作副本（`workingCopies`）。修订一经写入永不覆盖（重复 id 写入会被拒绝）。
- 修订载荷完整包含群、晶格尺寸、全部路径、样式与对象 ID，画布选择、实例定位与 PNG 导出始终对应当前修订。
- 创建检查点会封存当前分支：继续编辑自动切到新分支，下一个检查点成为新分支上的后代；从旧检查点“安全恢复”同样生成新分支上的工作副本，绝不篡改旧版本。恢复本身可撤销，对象 ID 与撤销/重做语义保留。
- “修订”页提供时间线（父修订、分支点标记）、分支筛选、任选两个修订的群/晶格/对象差异对比，以及安全恢复入口。
- 自动防抖保存携带工作副本世代；加载其他工程或切换修订会提升世代，迟到的旧计时器直接丢弃，不会写回新上下文。
- IndexedDB 从 v1 升级时，已有工程无损迁移为“迁移的初始修订”+ 工作副本，仍可打开；损坏或格式不支持的修订在恢复时明确失败，当前画布与既有检查点不受影响。
